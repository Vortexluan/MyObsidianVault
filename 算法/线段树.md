这个东西本质上就是用来处理区间问题的工具，RMQ（range maximum/minimum query,区间最值查询），RSQ（ range sum query 区间求和查询）都会用到这玩意。
我们通过一组数来构造对应的线段树，对于线段树中的每一个节点，都对应了数组序列中的一段子区间，父亲节点对子节点对应的信息进行整合。
本质上这就是分块思想的树化，就是对于信息处理的二进制化。我们对于一段需要查询的区间，可以将它分成分块和单个元素的并。
需要说明的是分块并不能认为等价于线段树，线段树的时间效率一般认为比分块要高，但是只能处理具有结合律性质的信息，比如max，min，sigma，xor这些调换顺序也不会影响的数据。

上面这些东西说完了，我们不妨来考虑自己写一个线段树，总共我们需要考虑一下三个部分：建树，修改，查询。（这些是一个数据结构最基本的部分，除此之外我们还有懒标记，关于这个我们等会再来讲）
首先我们来考虑建树

注意，对于一个长度为n的序列，我们建立的对应的树其节点数量只有2n-1，但是对应的最大编号则不超过4n-1
```Cpp
#define ll long long 
ll a[maxn],w[maxn*4];//note that a is the sequence and w is the tree


//！！this is how you add sonnodes up to fathernode and u refers to where the father is.make sure you already have the num of son nodes before use this function
void pushup (const u){
	w[u]=w[u*2]+w[u*2+1];//this is used to change and '+' can vary with question
}


void build (const u,int L,int R){
	if(L == R){
		w[u]=a[L];
	}
	int M=(L+R)/2;
	build(u*2,L,M);build(u*2+1,M+1,R);
	pushup(u);//this means when settled we change the fathers
}
```
其次我们再来考虑单点查询，顺便解决单点修改（修改本质上和查询相似，但是要注意回来的时候pushup）
如果我们要找p节点，实际上是找到[p,p]这样的区间，用p和M进行比较，遵从二叉树的规律来进行
```cpp
ll query(int u,int L,int R,int p){
	if(L==R){
		return w[L];
	}
	M=(L+R)/2;
	if(p<=M){
		query(int u*2,int L,int M,int p);
	}
	else{
		query(int u*2+1,int M+1,int R,int p);
	}
}


//and about changing
void update(int u,int L,int R,int p,ll x){//x is the number you want to change to,and p is where the position is
	if(L==R){
		w[u]=x;
	}
	M=(L+R)/2;
	if(p<=M){
		query(int u*2,int L,int M,int p);
	}
	else{
		query(int u*2+1,int M+1,int R,int p);
	}
	pushup(u);//!!note that you need to change it
}
```
这个时候我们就会意识到一件事情，如果仅仅是单点，那么直接使用数组即可，为何要使用线段树？线段树的优越之处正如同上所提及，在于对于区间的处理。（仅仅是查询的话那还算简单

现在，我们尝试处理区间查询
这里我们假设问题是给定l,r求区间[l,r]中的数字之和
```cpp
//我们先考虑l,r和L,R之间是否存在交集，写一个函数，注意这里的L，R是可以改变的，我们总是要进行判断,而且进行的是L和R在不在l和r区间内的判断（因为我们是使用L，R来不断拼凑区间的）
bool InRange(int L,int R,int l,int r){
	return (l<=L)&&(r>=R);
}
bool OutofRange(int L,int R,int l,int r){
	return (L>r)||(R<l);
}

ll query(int u,int L,int R,int l,int r){
	if(InRange(L,R,l,r))return w[u];
	else if(!OutofRange(L,R,l,r)){
		int M=(L+R)/2;
		return query(u*2,L,M,l,r)+query(u*2+1,M+1,R,l,r);
	}
	else{
		return 0;
	}
}
```
然后我们考虑相对复杂一点的区间修改（我们也要对查询做对应的修改）
在区间修改的时候我们不会暴力修改每一个叶子，为此我们引入延迟标记（懒标记/lazy tag）,当我们递归到一个被完全包含的区间的时候，我们给这个区间打上懒标记，表示这个区间的所有数值都要加上懒标记对应的数，然后直接修改该节点的区间的数值（加上对应的懒标记数值乘以区间长度）并返回（一路下来顺道处理lazy-tag），不再向下递归。当新访问到节点的时候，先将标记下放到子结点，再递归
```cpp
ll lzy[maxn*4];

//this is how you use you add tag
void maketag(int u,int len,ll x){//x means the number you want to add,len means the length of the interval
	lzy[u]+=x;//note that it's add not change
	w[u]+=len*x;
}
void pushdown(int u,int L,int R){//it's pushdown now not pushup
	int M=(L+R)/2;
	maketag(u*2,M-L+1,lzy[u]);maketag(u*2+1,R-M,lzy[u]);
	lzy[u]==0;//clearing is very important
}



//note that if you use range updating you have to change your way of using query accordingly
bool InRange(int L,int R,int l,int r){
	return (l<=L)&&(r>=R);
}
bool OutofRange(int L,int R,int l,int r){
	return (L>r)||(R<l);
}

ll query(int u,int L,int R,int l,int r){
	if(InRange(L,R,l,r))return w[u];
	else if(!OutofRange(L,R,l,r)){
		int M=(L+R)/2;
		pushdown(u,L,R);//we only modified our code here,the tag need to be used
		return query(u*2,L,M,l,r)+query(u*2+1,M+1,R,l,r);
	}
	else{
		return 0;
	}
}



//then try to range change
void update(int u,int L,int R,int l,int r,ll x){
	if(InRange(L,R,l,r)){
		maketag(u,R,L,x);
	}
	else if(!OutofRange(L,R,l,r)){
		int M=(L+R)/2;
		pushdown(u,L,R);//you need to pushdown before going down
		
		update(u*2,L,M,l,r,x);update(u*2+1,M+1,R,l,r,x);
		pushup(u);// and remember update father node 
	}
}
```
