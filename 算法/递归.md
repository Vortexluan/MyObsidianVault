[P1464 Function - 洛谷](https://www.luogu.com.cn/problem/P1464)
1.这道题目想要说的很显然，递归虽然很神奇，但是又时候是会去不断计算一个已经计算过的值的。这道题目要考虑的只有20 * 20 * 20但是却会有巨大的运算量，这个时候记忆化就是一种常见的优化手段。
2.看到这个破题下面的整数的逆天长度就知道不能够使用int，要用long long
3.注意他妈的printf输出也要整改，%d只能用来输出double的整数，我们需要使用%lld
4.由于这道题目的特殊性，很难注意到输出也是需要有回车的，在命令行里面的测试会有强制性的换行导致很难注意到这一点。
5.注意到这道题目测试样例-1 -1 -1的最后是没有回车的，我们不能使用在while内部的cin等到触发才进行，否则永远不会退出，合理的解决方式是使用
```cpp
while (cin >> a >> b >> c, a != -1 || b != -1 || c != -1)
```
