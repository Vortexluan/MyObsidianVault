这个排序算法可以用来计算逆序对数
[[逆序对数]]
来简单说明一下这个概念，假设我们有两个数组a,b,它们各自能够保持单调增
a:[1,5,7,9]
b:[0,6,7,8]
我们可以通过将a,b整合来得到一个更大的有序数组c
c[0,1,5,6,7,7,8,9]
如果能将一段大的，混乱的数组逐渐拆解，我们就能够通过这种方式从最小单元来进行数组的排序。以下示例我们去使用从小到大的排序方法
```cpp
int a[maxn]//我们假设a是一个从下标0到n的数组

			}
			else{
				c[k]=a[i];

			}
		}
		else if(i==n+1){
			c[k]=b[j];

		}
	}
}
```

这个时候我们再来考虑逆序对数的计算，就可以发现此时我们已经有了方法，如果i和j都是从0开始每当a[i++]之前，将a[i]放入，就意味这前面必然有对应j个的b中数字
```cpp
int a[maxn];
int t[maxn];
int num=0;
void MergeSort(int L,int R,int a[]){
	if(L==R)return ;
	int M=(L+R)/2;
	MergeSort(L,M,a);MergeSort(M+1,R,a);
	
	for(int i=0,j=0,k=M+1;i<=R;i++){
		if(j==M+1)t[i]==a[k++];//注意只计算一侧就可以了，不要重复计算
		else if(k==R+1){t[i]=a[j++];num=num+k-M-1;}
		else{
			//这个时候前面的三元运算符就不好用了，我们将其改造
			if(a[j]>a[k])t[i]=a[k++];
			else{
				t[i]=a[j++];
				num=num+k-M-1;
			}
			
		}
	}
	for(int i=0;i<=R;i++)a[i]=t[i];
}
```
